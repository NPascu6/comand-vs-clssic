# emit

## Purpose

`ThemeInputs` becomes each target. `typescript.ts` writes the literal the design system imports,
walking the schema so key order is the schema's; `flatten.ts` is the one flattening `css.ts`,
`json.ts` and `csharp.ts` share, with component colours resolved against each mode's palette —
a server has no theme to resolve a path against; `cssVariables.ts` is that flattening as custom
properties, and the diff a scope sets on its subtree.
