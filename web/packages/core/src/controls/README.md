# controls

## Purpose

MUI's `Button` and `IconButton`, forwarded with our variant and size vocabulary. Every visual
decision is a `component.button.*` token read by the theme's overrides — heights, inline paddings,
gap, radius, weight, and the colours of each variant — so a designer restyles every button in
every application from Figma.

A product that needs another variant adds its tokens and one override, in the same change.
