# layout

## Purpose

The frame, on MUI's `AppBar`, `Toolbar` and `Box`. `AppHeader` takes `start`/`end` adornments,
`onMenuToggle` for the side-menu button with `menuIcon`/`menuOpenIcon` for a product's own glyph,
`size` regular or compact, `surface`, `bordered`, and every `AppBar` prop such as `position`; `MenuButton` is exported on its own
for a bar built by hand. `Brand` is the app mark and name. `Page` is the body's inset and rhythm,
with an optional title row.

Every height, gap and rule is a `component.header.*` or `layout.*` token.
